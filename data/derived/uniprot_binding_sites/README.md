# UniProt Binding Sites On Disordered Residues

- Generated at (UTC): `2026-11-18T10:30:06Z`
- Generated by: `scripts/18_uniprot_binding_sites.jl`

UniProtKB `Binding site` features of the dataset proteins, fetched from
`https://rest.uniprot.org/uniprotkb/search`. Only sites overlapping at least one
DisProt residue labelled `1` (disorder) or `2` (binding) are kept.

## Inputs

- Dataset: `data/dataset/cluster_dataset_labels.csv.gz`
- UniProt release: `2026_04`

## Outputs

- uniprot_binding_sites.csv.gz: `3199 proteins`
- Proteins found in UniProt: `3132`
- Proteins with binding sites on disordered residues: `161`

## Parameters

- Accessions per request: `90`

## Columns

- `protein_disprot_id`: DisProt identifier of the dataset protein (key shared with the other derived CSVs)
- `protein_id`: UniProt accession of the dataset protein
- `uniprot_entry_found`: `true` when the accession was returned by the UniProt REST API
- `binding_in_uniprot`: `true` when at least one UniProt `Binding site` feature overlaps a DisProt residue labelled `1` or `2`
- `residues_binding_in_uniprot`: ranges of the kept binding sites on the UniProt sequence, e.g. `12-15;30` (`missing` if none)
- `publication_mention_binding`: number of PubMed evidences per kept site, same order (`missing` if none)
